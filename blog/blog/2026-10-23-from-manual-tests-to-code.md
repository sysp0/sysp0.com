I didn't start out wanting to write software. I started in networking, as a QC intern.

<!-- truncate -->

## Where it began

My job was to research static routing scenarios so the team could test the company's own routers and switches. I ran functional and quality tests on products before release, and I wrote documentation on Cisco and networking technologies for the team.

## The moment it turned

Running the same test by hand, again and again, got old. The thought that kept coming back was: a machine should be doing this part.

## What happened next

I started writing Python packages that automated the QC team's daily work. Then I built the backend of a web platform that could run those tests, with Django, Celery and RabbitMQ. Tests started from a web app instead of from someone's terminal.

## What I took from it

Boredom was a useful signal. It pointed at the part of the work that wanted to become a system. Everything I've built since started with that question: why is a person doing this by hand?
